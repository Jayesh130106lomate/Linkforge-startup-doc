## 2. Document Archival & Storage Rules

When adding official certificates or licenses to this folder in the future:

1. **Preserve Original Files**: Store original PDFs or high-resolution official scans directly without modifying image content, text, or digital signatures.
2. **Clear Naming Standard**: Name files clearly with the registration identifier and document type (e.g., `GSTIN-XXXXX-Registration-Certificate.pdf`).
3. **No Fake or Placeholder Files**: In accordance with startup documentation integrity rules, never create blank, dummy, or sample certificate files.
4. **Restricted Access**: Government certificates contain sensitive identity details; ensure repository permissions protect these files against public exposure.
